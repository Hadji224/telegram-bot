Contexte et présentation

Comprendre pourquoi LinkLink existe et d'où l'on part.

1.1 Présentation de LinkLink

LinkLink est une startup fondée par 6 associés souhaitant se doter d'un outil interne centralisé pour piloter leurs projets et, à terme, gérer leurs clients depuis une plateforme unique.

1.2 Situation actuelle

Aujourd'hui, l'équipe utilise :

  • WhatsApp pour les communications et le partage de fichiers
  • Aucun outil structuré pour les tâches, les rendez-vous et le suivi de projets
  • Des fichiers dispersés entre téléphones et clouds personnels

Problèmes identifiés

ProblèmeImpact
Fichiers compressés/expirés sur WhatsAppPerte de documents importants
Absence d'arborescenceRecherche chronophage
Pas de suivi de tâchesOublis, retards, doublons
Pas de permissionsTout le monde voit tout
Pas de calendrier partagéDifficulté à planifier
Historique non exploitablePerte de connaissance

1.3 Nature du projet

Il s'agit d'une plateforme interne privée (non SaaS, non commercialisée), destinée :

  1. Phase 1 — Aux 6 fondateurs uniquement
  2. Phase 2 — Ouverture progressive à des clients/partenaires externes via un portail dédié
⚠️

Confidentialité — Le projet est développé en secret par un seul fondateur. Aucune information ne doit fuiter avant la présentation officielle à l'équipe.

Besoins fonctionnels détaillés

Chaque module, chaque fonctionnalité, sans rien oublier.

5.1 Module — Authentification & Comptes

F-AUTH-01 — Inscription

  • Inscription sur invitation uniquement (pas d'auto-inscription)
  • Champs : nom, prénom, email, mot de passe (min. 12 caractères)
  • Validation par email obligatoire

F-AUTH-02 — Connexion

  • Email + mot de passe
  • Option "Se souvenir de moi" (30 jours)
  • Verrouillage après 5 échecs (15 min)

F-AUTH-03 — Récupération de mot de passe

  • Lien par email, valable 1h
  • Force un mot de passe fort à la réinitialisation

F-AUTH-04 — Double authentification (2FA)

  • Optionnel en Phase 1, obligatoire pour Super Admin
  • Via application TOTP (Google Authenticator)

F-AUTH-05 — Profil utilisateur

  • Avatar, nom, rôle, statut, bio courte
  • Statut de présence : En ligne / Absent / Hors ligne

5.2 Module — Projets

F-PROJ-01 — Création de projet

  • Champs obligatoires : nom, description, couleur, statut
  • Champs optionnels : date début, date fin, budget
  • Le créateur devient automatiquement membre

F-PROJ-02 — Liste des projets

  • Vue grille ou liste
  • Filtres : statut (actif/pause/terminé), membre, date
  • Recherche par nom

F-PROJ-03 — Détail projet

  • Onglets : Vue d'ensemble, Tâches, Dossiers, Messages, RDV, Membres, Activité
  • Progression automatique (% tâches terminées)
  • Actions rapides : ajouter tâche, ajouter fichier, inviter

F-PROJ-04 — Membres du projet

  • Ajout/retrait de fondateurs
  • Rôle dans le projet : Responsable / Contributeur / Observateur

F-PROJ-05 — Archivage

  • Un projet terminé peut être archivé (non supprimé)
  • Reste consultable, non modifiable

5.3 Module — Tâches

F-TASK-01 — Création de tâche

  • Champs : titre, description, assigné à, échéance, priorité, statut, tags
  • Pièces jointes possibles
  • Sous-tâches (checklist)

F-TASK-02 — Vues multiples

  • Kanban : À faire / En cours / En révision / Terminé
  • Liste : tri par échéance, priorité, assigné
  • Calendrier : échéances sur un mois
  • Ma journée : tâches assignées à moi pour aujourd'hui

F-TASK-03 — Priorités

🔴 Urgent / 🟠 Élevée / 🟡 Moyenne / 🟢 Basse

F-TASK-04 — Commentaires

  • Fil de discussion par tâche
  • Mentions @utilisateur (notifie)

F-TASK-05 — Récurrence

  • Option : quotidienne, hebdomadaire, mensuelle

F-TASK-06 — Notifications

  • Assignation → notification instantanée
  • Échéance J-1 et J-0 → rappel
  • Tâche en retard → alerte

5.4 Module — Dossiers & Fichiers

F-FILE-01 — Upload

  • Glisser-déposer + sélection classique
  • Taille max par fichier : 100 MB
  • Formats supportés : PDF, DOCX, XLSX, PPTX, images, ZIP, vidéos légères

F-FILE-02 — Arborescence

  • Dossiers et sous-dossiers illimités
  • Un dossier racine par projet

F-FILE-03 — Versioning

  • Conservation des versions précédentes
  • Comparaison visuelle des versions (date, auteur, taille)

F-FILE-04 — Permissions

  • Par dossier : qui peut voir / modifier
  • Par défaut : tous les membres du projet

F-FILE-05 — Recherche

  • Recherche par nom, type, auteur, date, projet

F-FILE-06 — Aperçu en ligne

  • PDF, images, Office (via visionneuse intégrée)

F-FILE-07 — Partage externe Phase 2

  • Lien sécurisé avec expiration
  • Accès protégé par mot de passe (optionnel)

5.5 Module — Messagerie

F-MSG-01 — Fils de discussion

  • Un fil par projet
  • Fils directs entre deux membres
  • Fils thématiques (créés manuellement)

F-MSG-02 — Messages

  • Texte enrichi (gras, italique, listes, liens)
  • Pièces jointes (renvoi vers module Dossiers)
  • Réactions emoji

F-MSG-03 — Mentions

  • @utilisateur → notification
  • @tous → notification à tous les membres du projet

F-MSG-04 — Accusés de lecture

  • Indicateur lu/non lu par message
  • Compteur de non-lus par fil

F-MSG-05 — Recherche

  • Recherche plein texte dans tous les messages

F-MSG-06 — Épinglage

  • Épingler un message important en haut du fil

5.6 Module — Rendez-vous

F-RDV-01 — Création de RDV

  • Titre, description, date/heure début et fin, lieu (physique ou visio)
  • Invités (membres + optionnellement clients en Phase 2)
  • Récurrence possible

F-RDV-02 — Créneaux de disponibilité

  • Chaque membre peut définir ses créneaux
  • Vue "trouver un créneau commun"

F-RDV-03 — Rappels

  • 24h avant, 1h avant, 10 min avant (configurable)
  • Canaux : email + notification in-app

F-RDV-04 — Lien visio

  • Génération automatique d'un lien Jitsi ou Google Meet
  • Intégration dans la description du RDV

F-RDV-05 — Calendrier

  • Vue mois / semaine / jour
  • Vue par membre ou globale

F-RDV-06 — Réponses

  • Accepter / Refuser / Peut-être
  • Statut visible par tous les invités

5.7 Module — Tableau de bord

F-DASH-01 — Vue personnelle

  • Mes tâches du jour
  • Mes RDV à venir
  • Mes projets actifs
  • Derniers messages non lus

F-DASH-02 — Vue globale (Super Admin)

  • Toutes les tâches en retard
  • Charge par membre
  • Progression de chaque projet
  • Activité récente

F-DASH-03 — KPIs

  • Nombre de projets actifs
  • Tâches terminées cette semaine
  • RDV de la semaine
  • Nouveaux fichiers

F-DASH-04 — Graphiques

  • Progression par projet (courbe)
  • Répartition des tâches par statut (donut)
  • Charge par membre (barres)

5.8 Module — Notifications

F-NOTIF-01 — In-app

  • Cloche avec compteur
  • Liste déroulante des 20 dernières

F-NOTIF-02 — Email

  • Résumé instantané pour mentions/assignations
  • Digest quotidien (8h) et hebdomadaire (lundi 8h)

F-NOTIF-03 — Préférences

  • Par utilisateur : activer/désactiver par type
  • Choisir canal : in-app / email / les deux

5.9 Module — Journal d'activité

F-LOG-01 — Traçabilité

  • Enregistrer chaque action : qui, quoi, quand, où

F-LOG-02 — Consultation

  • Filtrer par utilisateur, projet, type, date
  • Export CSV

5.10 Module — Administration

F-ADMIN-01 — Gestion utilisateurs

  • Créer / désactiver / supprimer un compte
  • Renvoyer une invitation
  • Forcer 2FA

F-ADMIN-02 — Paramètres généraux

  • Nom de la structure, logo, couleurs
  • Fuseau horaire, langue

F-ADMIN-03 — Modèles

  • Modèles de messages, de tâches, de projets

5.11 Module — Clients Phase 2

F-CLIENT-01 — Fiches clients

  • Nom, contact, entreprise, historique
  • Projets liés
  • Documents partagés

F-CLIENT-02 — Portail client

  • Accès sécurisé avec compte dédié
  • Le client voit : son projet, ses RDV, ses documents partagés, sa messagerie

F-CLIENT-03 — Messagerie client

  • Fil unique par client
  • Notifications

F-CLIENT-04 — Facturation Optionnel

CritèreCible

6.2 Disponibilité

  • Uptime cible : 99,5% (hors maintenance planifiée)
  • Maintenance : fenêtre nocturne, préavis 48h

6.3 Scalabilité

  • Architecture prête pour 50 utilisateurs et 100 projets
  • Migration future vers multi-tenant possible

6.4 Compatibilité

  • Navigateurs : Chrome, Firefox, Safari, Edge (2 dernières versions)
  • OS : Windows, macOS, Linux, iOS, Android (via navigateur)
  • Responsive : mobile-first pour les écrans ≥ 375 px

6.5 Ergonomie

  • Interface en français
  • Accessibilité WCAG AA
  • Navigation clavier complète
  • Feedback visuel sur chaque action

6.6 Sécurité

  • HTTPS obligatoire
  • Chiffrement en transit (TLS 1.3) et au repos (AES-256)
  • Mots de passe hashés (bcrypt ou Argon2)
  • Protection CSRF, XSS, injection SQL
  • Rate limiting sur endpoints sensibles
  • Logs d'accès conservés 12 mois

6.7 Sauvegarde

  • Base de données : sauvegarde quotidienne, rétention 30 jours
  • Fichiers : réplication géographique
  • RPO : 24h — RTO : 4h
  • Test de restauration mensuel

6.8 Conformité

  • RGPD : registre des traitements, droit d'accès, droit à l'oubli
  • Hébergement : UE (France de préférence)
  • CGU + Politique de confidentialité rédigées

Sécurité et conformité

Protection des données, RGPD, journalisation.

9.1 Authentification

  • Mots de passe : min. 12 caractères, 1 maj, 1 min, 1 chiffre, 1 spécial
  • Hashing : Argon2id
  • 2FA obligatoire pour Super Admin
  • Sessions : expiration 30 jours max

9.2 Autorisation

  • Row Level Security (RLS) activé sur toutes les tables sensibles
  • Politique : un utilisateur ne voit que les données des projets dont il est membre
  • Vérification côté serveur systématique

9.3 Protection des données

  • Chiffrement en transit : TLS 1.3
  • Chiffrement au repos : AES-256
  • Fichiers sensibles : URLs signées à durée limitée

9.4 RGPD

  • Registre des traitements tenu à jour
  • Consentement explicite à l'inscription
  • Droit d'accès : export des données en 1 clic
  • Droit à l'oubli : suppression en cascade
  • DPO : le Super Admin

9.5 Journalisation

  • Toutes les actions sensibles sont loguées
  • Conservation 12 mois
  • Accès aux logs : Super Admin uniquement

Stratégie de tests et recette

Comment on s'assure que tout fonctionne.

14.1 Types de tests

TypeObjectifOutils
UnitairesTester chaque fonctionVitest
IntégrationTester les interactionsVitest + Testing Library
E2ETester les parcours utilisateursPlaywright
ManuelsVérifier l'UXChecklist
PerformanceVérifier les temps de réponseLighthouse
SécuritéVérifier les faillesOWASP checklist

14.2 Scénarios critiques à tester

  1. Inscription → connexion → dashboard
  2. Création projet → ajout membre → création tâche
  3. Upload fichier → partage → versioning
  4. Envoi message → réception temps réel → notification
  5. Création RDV → invitation → acceptation → rappel
  6. Suppression projet → confirmation → archivage

14.3 Critères d'acceptation

  • ✅ 100% des scénarios critiques passent
  • ✅ 0 bug bloquant
  • ✅ Score Lighthouse > 85
  • ✅ Audit sécurité OWASP : aucun point critique

Déploiement et mise en production

Comment on livre et on sécurise la mise en ligne.

15.1 Processus

  1. Développement sur branche dev
  2. Tests sur environnement staging
  3. Validation par le fondateur
  4. Merge sur main
  5. Déploiement automatique via Vercel
  6. Vérification post-déploiement

15.2 Checklist de mise en production

  • Variables d'environnement configurées
  • Domaine pointé et SSL actif
  • Backups activés
  • Monitoring Sentry actif
  • Analytics configuré
  • CGU et politique de confidentialité en ligne
  • Test de restauration DB effectué

15.3 Rollback

  • Sauvegarde du dernier état stable
  • Redéploiement en 1 clic via Vercel
